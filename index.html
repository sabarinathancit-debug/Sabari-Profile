The Profile

Every release has a weak point before it ships — a missed edge case, a regression hiding behind a clean build. Sabarinathan's job is to find it first. Across a career spent inside the software development lifecycle, that's meant reading client requirements like case notes, writing test plans that leave nothing to chance, and working shoulder to shoulder with developers until every defect is closed out.

The tools are unglamorous but reliable: Core Java for scripting logic, Selenium WebDriver and TestNG for structured checks, Oracle and PostgreSQL for chasing data down to the row. The instinct behind them — patience, thoroughness, and a refusal to let "probably fine" pass for "tested" — is what six years on the job actually builds.
